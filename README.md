## 五、服务器基础知识框架整理（补充）

> 以下为根据文章章节框架补充的知识脉络，便于建立整体认知。

### 1. 服务器整体
- 与 PC 的区别：稳定性、扩展性、可管理性、7×24 不间断运行
- 形态：塔式 / 机架式 / 刀片式
- 核心指标：算力、IO、可靠性（RAS）、功耗（TDP）、可扩展性

### 2. CPU
- 主流平台：Intel Xeon（至强）、AMD EPYC（霄龙）、国产（鲲鹏 / 飞腾 / 龙芯 / 海光 / 兆芯）
- 关键概念：核心数、线程、主频、缓存（L1/L2/L3）、指令集（x86 / ARM）
- 多路（Socket）与 NUMA 架构

### 3. 内存
- 类型演进：DDR4 → DDR5；服务器普遍采用 ECC 内存纠错
- 关键指标：容量、频率、带宽、通道数
- RAS：错误检测与纠正（ECC / 内存镜像 / 热备）

### 4. GPU
- 用途：AI 训练/推理、HPC 高性能计算加速
- 英伟达架构演进：Fermi → Kepler → Maxwell → Pascal → Volta → Turing → Ampere → Hopper → Rubin（Ultra）
- 关键指标：CUDA 核心数、显存类型与容量（GDDR / HBM）、显存带宽、NVLink 互联

### 5. 存储 / 硬盘
- 介质：HDD（机械盘）、SSD（SATA / NVMe）
- 接口与协议：SATA、SAS、NVMe（走 PCIe）
- 可靠性：RAID（0/1/5/6/10）、热备、快照
- 指标：容量、IOPS、吞吐、时延

### 6. 网络 / 智能网卡
- 普通网卡 vs 智能网卡（SmartNIC / DPU）
- 智能网卡能力：卸载（OVS / 存储 / 加密 / 安全）、可编程
- 速率演进：10G → 25G → 100G → 400G

### 7. 操作系统与虚拟化
- 服务器 OS：Linux（主流）、Windows Server
- 虚拟化：Hypervisor 虚拟化、容器（Docker / Kubernetes）
